Building the engine yourself

The engine/ folder in the repository contains everything needed to build the janggi-engine.wasm this site serves.

FileContents
build.shDownloads the original source (pinned commit) and wasi-sdk 25, applies the patch and builds
patches/single-thread.patchChange to the original thread.cpp: runs the search in place without a separate thread
wasi_single_thread.hLock and thread stand-in types for the thread-less WASI environment
wasi_stubs.cppEmpty implementations of two functions missing from WASI (__cxa_thread_atexit, madvise)

Original: Fairy-Stockfish commit 52838835f7234e29fb48fd88eb39fb3c7e46fcfa (2026-11-19). Clone the repository and run ./engine/build.sh to produce the same file.

Changes from the original

  • Changed to run on one thread instead of several, so it works in the browser without special server headers.
  • Built as WASI WebAssembly, with a small runner (site/assets/engine/v1/engine-worker.js) that emulates standard input and output in the browser.
  • The neural network (NNUE) file is not included, so the engine uses the classical evaluation.
  • The rules library ffish-es6 0.7.10 is used unmodified from npm. Its source is in the Fairy-Stockfish repository.
